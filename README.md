# 📊 Electronics Product Inventory Table

A clean and structured HTML data table displaying inventory, pricing, and total calculations for various electronics products[cite: 2].

## ✨ Features

* **📋 Tabular Data Layout:** Organized using standard HTML table tags (`<table>`, `<tr>`, `<th>`, `<td>`) with border-collapse styling[cite: 2].
* **🎨 Custom Styling:** Features a centered table layout with styled navy blue header cells, contrasting white text, and defined row heights[cite: 2].
* **🧮 Summary Row:** Includes a spanned footer row (`colspan="4"`) highlighting the grand total amount across all inventory[cite: 2].

## 📂 File Structure

* `Table.html` - The core HTML file containing the product data table structure and embedded CSS styling[cite: 2].
